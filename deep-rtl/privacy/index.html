Deep RTL Toggle — Privacy Policy

Effective date: 4 November 2026
Developer: Arman Nakhaeirad

Purpose

Deep RTL Toggle changes website layout and text direction to make right-to-left and mixed-language content easier to read.

Page text processed on your device

When RTL mode is enabled on supported Claude, ChatGPT, Gemini, and Grok pages, the extension reads rendered prose and leaf sidebar labels in the current page to choose their reading direction. This content can include displayed conversations and their titles. Processing takes place locally in the browser. The extension does not rewrite this text, persist it to extension storage, export it, or transmit it to the developer or another server. Code and mathematical content are excluded from paragraph classification. The extension does not request an account, upload chats, or include analytics or advertising.

Preferences saved with Chrome

The extension stores selected website hostnames and their RTL/LTR settings, plus font size and font-family preferences, using Chrome storage.sync. These hostnames are the sites for which a direction preference is saved; the extension does not keep a separate browsing-history log. Chrome may synchronize these preferences through the user's browser account when Chrome sync is enabled. Google handles that browser sync service under its own privacy terms. Conversation text is not included in these saved preferences.

Use and sharing

Locally processed text is used only to select reading direction. Saved preferences are used only to remember and apply the user's chosen layout and typography. The developer receives no chat content or saved preference data from the extension. The extension does not sell user data, use it for advertising, or transfer it for purposes unrelated to its reading and layout features.

Your controls

Choose Off in the popup to remove the saved direction override for the current hostname and restore the site's original layout. Change font preferences in Settings. Browser sync controls are managed by Chrome. Removing the extension removes its local extension data according to Chrome's behavior; management of any browser-synced data is governed by Chrome's sync controls.

External links

The extension includes an Instagram link and an optional support link. They open only when clicked. Those websites have their own privacy practices and may receive the usual information associated with a browser visit. The extension does not attach chat text or preference data to those links.

Limited Use

The extension's use of information adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements. Page text is used only for the disclosed, user-facing reading-direction feature.
